Privacy & usage analytics

Solenary automatically records approximate active-use minutes for signed-in accounts. Time pauses when the tab is hidden or you're idle. Administrators can see your registration email, sign-up date, last sign-in and daily usage totals. We don't record task contents, keystrokes or which pages you visit.

Read the usage and privacy notice for details, including how you can request access or removal.

Daily usage totals are collected automatically while you use Solenary.

Deleting previous usage data does not stop collection during later active sessions. You can also request help with your data from the site owner.

Notifications

Google Calendar ↔ Solenary

SECURE CONNECTION

Solenary uses Google’s permission screen; your Google password and tokens are never stored in this website’s GitHub files.

Checking connection…

First-time setup: the Solenary administrator must deploy the secure Supabase Edge Function.

When two-way sync is enabled, existing Solenary tasks in the next year can be created as Google events. Both calendars may change when you edit or delete a linked event. Conflicting edits are not overwritten automatically.

Automatic syncChecking your connection…

Last successful sync: Never

Syncs events from 30 days ago through 365 days ahead. Multi-day and overnight events are left untouched in Google for now. Checks for Google changes every 2 minutes while the page is open, and sends saved Solenary changes automatically when two-way mode is on. Background updates when closed require Supabase Cron setup. Google Tasks are separate from Calendar events.

ONE-TIME CALENDAR HANDOFFS Choose one of your personal tasks

Solenary opens a prefilled calendar event or downloads a file. Edits made there do not automatically sync back.

MAIL Share a summary only when you choose

Only task titles, dates and times from the next seven days are placed in the draft—no private task notes. Review recipients and contents before sending.

DOCUMENTS & FILES Attach links in any task editor

Paste any HTTPS Docs, Sheets or OneDrive URL into a Solenary task's “Related document link” field. Link permissions still depend on the external service.
