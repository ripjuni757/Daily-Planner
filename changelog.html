PRODUCT UPDATES / RELEASE NOTES

Changelog

A record of improvements to Solenary. Features may require setup in your account before becoming available.

v.11 — Automatic Calendar Sync

LATEST

Less clicking, more planning.

  • Saved Solenary event changes trigger a debounced Google Calendar sync when two-way mode is enabled and an initial sync has completed.
  • Checks for Google-side changes every two minutes while Solenary is visible, plus an update after returning to the tab.
  • Improved connection, syncing, conflict, and retry status in Integrations.
  • Optional Supabase Cron setup for scheduled syncing while the website is closed.
  • Clickable version label beside the Solenary name opens this changelog.

v.10 — Google Calendar

  • Google account authorization and selectable calendars.
  • Two-way event synchronization, with import-only mode as the starting setting.
  • Server-side tokens, linked events, and protection against conflicting simultaneous edits.

v.9 — School Planning

  • Cannon Upper School’s three-day rotating schedule, block mapping, and personal class setup.
  • School selection during signup and in account settings; eligible Upper School students see US Planner.

v.8 — Administration Analytics

  • Admin user and feedback reporting, with activity-minute tracking and privacy disclosures.

v.7 — Solenary

  • Navy-and-gold Solenary identity and simplified navigation.
  • Private administration dashboard and feedback inbox.

Earlier versions

  • Daily Compass, Reality Check, Deadline Runway, Rebuild Week, and weekly reflection.
  • Recurring weekly activities, personal work/school hours, and differentiated calendar colors.
  • Supabase accounts, personal cloud saving, and shared spaces.

Solenary is an independently developed planner. Some integrations are experimental and may not be enabled for all users. If you notice a syncing issue, keep a backup of your calendar and report the issue through Solenary's feedback form.
